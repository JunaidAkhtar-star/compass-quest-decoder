# ⚡ Project COMPASS

A premium EV Charging Mobile Application designed as part of the **Zidio UI/UX Internship**.

Project COMPASS helps electric vehicle users discover charging stations, plan routes, monitor charging sessions, manage payments, and track charging history through a modern, intuitive, and user-friendly interface.

---

## 🚀 Features

- 🔐 User Authentication
- 📍 Find Nearby Charging Stations
- ⚡ Live Charger Availability
- 🗺️ Route Planning
- 🔋 Start & Monitor Charging Sessions
- 💳 Secure Payments
- 👛 Digital Wallet
- 📜 Charging History
- 🚗 Saved Trips
- 👤 User Profile & Settings
- ❓ Help & Support
- 📱 Responsive Mobile Design
- ♿ WCAG AA Accessibility

## ⚙️ Setup Steps

### 1. Clone the Repository

```bash
git clone https://github.com/SumitGupta-cse-ai/compass-quest-decoder.git
```

### 2. Navigate to the Project

```bash
cd compass-quest-decoder
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```
